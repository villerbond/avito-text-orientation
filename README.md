# Avito Text Orientation

Проект по классификации ориентации текста на изображениях. Задача состоит в том, чтобы определить, перевернут ли текст на 180° или находится в нормальной ориентации.

```

│   └── 03_inference.ipynb                 # ноутбук для предсказания по тестовым данным
└── README.md
```

## Создание датасета

### Источники данных

Для обучения был выбран датасет **RusTitW** (Russian Language Visual Text Recognition), так как он:
- Содержит как реальные, так и синтетические изображения
- Включает текст на русском и английском языках
- Предоставляет разметку текстовых областей

### Процесс создания

1. **Загрузка исходных данных**: Скачивание изображений и метаданных из RusTitW (real и synth части)

2. **Извлечение кропов**: 
   - Вырезание текстовых кропов из исходных изображений

3. **Формирование классов**:
   - **Класс 0**: оригинальная ориентация текста
   - **Класс 1**: текст, повернутый на 180°

4. **Разделение на train/val**:
   - Train: основное множество для обучения
   - Validation: для контроля переобучения

5. **Сохранение**: Датасет упакован в архив и загружен на Google Drive для удобства использования

## Выбор моделей

Для задачи бинарной классификации ориентации текста были выбраны следующие архитектуры:

### 1. **ResNet18** (основная модель)
- Предобучена на ImageNet

### 2. **EfficientNet-B0**
- Более легкая архитектура

### 3. **MobileNetV3 Small**
- Очень легкая модель

### 4. **ShuffleNetV2**
- Эффективная для мобильных устройств

**Результат**: ResNet18 показала наилучшие результаты (~92% accuracy на валидации).

## Валидация

### Метрика
Основная метрика: **Brier Score**

### Стратегия валидации
- Разделение данных на train/validation
- Batch size: 32 (оптимальный баланс стабильности и скорости)
- Сохранение лучшей модели по validation score

### Результаты
- Все модели склонны к переобучению после 4-5 эпохи
- ResNet18: ~92% accuracy на валидации
- Применение аугментации данных улучшило стабильность обучения

## Обучение

### Гиперпараметры
```python
batch_size = 32
learning_rate = 1e-4
epochs = 10-15
optimizer = Adam
loss_function = BCEWithLogitsLoss
```

### Аугментация
Для улучшения обобщающей способности модели применялись:
- Gaussian Blur (p=0.3)
- Color Jitter (brightness=0.1, contrast=0.1)
- Случайный шум
